# ForTy-TSViT

第一篇论文的模型、训练及评估代码在本仓库维护。

## U-Net 模型

- `forest_unet.py`：40 通道、8 类的基础 U-Net，以及可开关的 1/4、1/2 解码特征细化支路。
- `forty_adapter.py`：S2 通道排列、缩放和标签映射的候选接口，待与训练数据联合核验。
- `metrics_reference.py`：统一标签空间下的指标参考，保留预测 unknown 导致的漏检；不自动替换现有训练脚本的指标。

模型配置、输入标签约定及接入示例见 [U-Net 使用说明](docs/unet.md)。

目前已完成合成输入结构检查；真实数据冒烟和边缘版 50 epoch 训练 mIoU ≥95% 仍待验收。
