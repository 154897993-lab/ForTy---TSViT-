# 验收清单修订建议（草案）

日期：2026-11-16  
状态：**待负责人确认，不是已冻结协议**  
适用：500 pilot 后的阶段二/阶段三验收；不改动官方 test 封存流程。

## 一、口径

- **主口径**：阮的 budget-matched 评估，S0 clean、S1 单季、S2 双季独立、S3 双季重叠；每个 validation 样本四场景，共 2000 行。
- **附录**：固定严口径极端场景（如果负责人要求保留）只作稳健性附录，不与主表混排。
- **指标**：八类 mIoU；森林三类（原始 1–3）宏 F1；人工林（原始 2）F1；整图与边界带分开。
- **边界**：GT 4 邻域异类跃迁，Chebyshev 膨胀半径 2，排除 unknown 邻域半径 2；边界分数不替代整图分数。

## 二、建议门槛（草案）

| 项 | 建议门槛 | 说明 |
| --- | --- | --- |
| 退化收益 | B−A 在 S1/S2/S3 各场景 ≥ +2 个百分点（或三场景平均 ≥ +2） | B 指独立/重叠云训练组，A 为 clean 无边缘 |
| clean 代价 | B 的 S0 相对 A 的降幅 ≤ 1 个百分点 | 避免用退化训练换来不可接受的 clean 退化 |
| D 边缘支路 | 边界带 mIoU ≥ +1 个百分点，且整图 mIoU 不下降 | 使用新边界定义；D−A、B+D−B 分别报告 |
| 稳定性 | 三种子均值 ± 样本标准差；配对差按种子对齐 | 单种子只作方向性，不作科研结论 |
| 数据范围 | 500 pilot 用于选配置；3000 全量用于主表 | 不把 500 结果写成全量结论 |

## 三、预期区间重标

- A 组 pilot mIoU 原清单预期 55–63，按当前实测改为 **50–55 量级**；全量数据出来后再复核。
- 人工林 F1 的 40–60 预期暂不写死；以全量数据的逐类 F1/support 为准，ice 类稀缺需单独标注。

## 四、验收执行顺序

1. 固定数据、评估清单、引擎/评估器源码哈希。
2. 六组 × 三种子全量训练；checkpoint 交阮的固定入口。
3. 输出 S0–S3、逐类、边界、覆盖率/掩膜 IoU、样本误差。
4. 按本草案检查主门槛；通过后进入决策点 1。
5. 决策点 2 后才解封 test，且只执行一次。

## 五、待确认

- 主口径是否只留 budget-matched，还是保留固定严口径附录。
- `B−A` 的 +2 点按每个场景还是三场景平均；建议两者都报告，主判定用平均并附逐场景。
- `D` 边界门槛以哪个 batch 为准；建议在全量三种子、冻结 batch 后判定。
