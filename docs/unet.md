# U-Net 模型与输入约定

模型版本 unet_v0.1；训练链路为独立实现，不依赖旧 TSViT 或 Sobel 代码。

## 结构与六组

基础 U-Net 使用 40 通道输入、8 类输出。编码通道为 16/32/64/128/256，四次最大池化；解码端双线性插值并拼接同尺度编码特征。输出为未归一化 logits `[B,8,128,128]`。基础模型 1,969,544 参数。

内置细化支路融合解码器 1/4、1/2 尺度特征，输出残差 logits；新增 8,680 参数即 0.4407%。不使用额外边缘标签、边缘损失、NDVI 或 Sobel 旁路。是否有效需真实消融验证。

```python
from model import build
net = build("B_ind+D")
```

A/D 为干净训练无/有支路；B_ind/B_ind+D 为独立云训练无/有支路；B_ovl/B_ovl+D 为重叠云训练无/有支路。云由独立协议接口处理，模型工厂只选择结构。相同初始化种子下，共享主干初始权重一致；训练顺序和云随机源也需固定。

## 统一输入与标签

- 数据读取器返回归一化后的 `[B,4,128,128,10]`，只除协议的 divisor 一次，默认候选值 10000。缺测填补和裁剪不自动引入。
- 候选季节顺序 DJF/MAM/JJA/SON，波段 B2/B3/B4/B5/B6/B7/B8/B8A/B11/B12，由阮确认后冻结。
- `flatten_s2` 只排列通道，不再次缩放；索引为季节索引×10＋波段索引。单独的 `prepare_s2` 接收原始 DN，不用于已经归一化的数据路径。
- 原始标签 0 为 unknown，1–8 为天然林、人工林、树作物、其他植被、建筑、水体、冰雪、裸地。
- 新训练入口统一调用 `encode_labels`：unknown→-1，1–8→0–7；整批无有效标签时跳过反向和优化器更新。
- 推理 argmax 后加一还原为原始 ID 1–8。忽略标签统一使用 -1，与阮的评估协议一致；不做二次标签映射。

## 指标与 checkpoint

先累计全数据集混淆矩阵，再计算分数。unknown 真值不参与，其他模型的 unknown 预测仍算漏检；森林宏 F1 为原始类别 1–3 的算术平均，整体宏 F1/宏 IoU 为八个有效类平均。无分母类别按 0 并返回 support，须在协议中确认。

边界带由相邻、均有效且类别不同的标签像素产生，再按冻结宽度膨胀并排除 unknown。该定义属于新协议，不能把旧 Sobel/旧边界统计直接混入。宽度 0 表示不计算边界分数，缺少边界支持时返回空值。

新 checkpoint 顶层含 `model_version`、`model_config`、`state_dict`、`optimizer`、`epoch`；`provenance` 含组名、训练种子、scope、交付协议哈希、运行协议哈希、训练清单哈希、评估清单哈希、模型/引擎/训练云包装源码哈希，供阮的统一评估器核验。它与旧 TSViT 格式不兼容。本地 `evaluate.py` 仅作诊断，正式四场景评估由阮的固定入口执行；不要手动使用旧加载入口。

每轮可在 eval 模式下计算完整的干净训练集分数，供 50 epoch 验收使用；字段为 history.json 中 train_clean.whole.miou，单位 0–1。它不是训练批次在线准确率，也不是验证集分数。验收的小样本规模仍由双方事前确定。
