# 设计演进决策记录

日期：2026-11-16  
状态：记录已在代码/文档中落地的变化，以及需要负责人确认的部分。

## D-01 评估口径

- 变化：从“固定严口径”扩展到阮的 budget-matched 训练/评估同分布口径；固定严口径保留为可选稳健性附录。
- 原因：训练云和评估云必须同分布，否则 S1–S3 的退化收益会被训练/评估分布错配混淆；固定严口径仍可用于外部对照。
- 影响：主表使用 S0–S3 的 2000 行冻结评估清单；所有 checkpoint 必须带交付协议、数据/评估清单、引擎和训练云源码哈希。
- 状态：清单 v2 第十四节决策点 0 第 1 条已确认双口径（budget-matched 主表 + 固定严口径稳健性附录）；实施细节见 `docs/清单修订建议_20261116.md`。

## D-02 边界定义

- 变化：边界带改为 GT 4 邻域异类跃迁，Chebyshev 膨胀半径 2，并排除 unknown 邻域半径 2。
- 原因：旧 Sobel/旧边界统计与当前标签和 unknown 处理不一致，无法直接比较。
- 影响：边界 mIoU/forest F1 从新定义重新计算；不能与旧数字拼接。
- 状态：已在 `pipeline.py` 和阮评估输出中实现；属于新协议，不回溯改写旧结果。首次边界带测量已完成（`evidence/20261116_pilot500/evaluation/boundary_metrics.csv`）：batch32 的 D−A 边界 mIoU 在 S0–S3 为 -0.99/-1.48/-2.61/-0.80 点，D 单独未达 v2 的 +1 点门槛；B+D−B 为 +1.5 到 +2.7 点。pilot 单种子只作方向，正式判定待三种子。

## D-03 B 因子拆分为独立/重叠六组

- 变化：B 因子拆为 B_ind、B_ind+D、B_ovl、B_ovl+D；A/D 保持 clean。
- 原因：独立云和重叠云的空间关系不同，混成一个 B 组会丢失跨季重叠效应；边缘支路分别与两种云组合。
- 影响：主表比较六组，不允许把 B_ind 与 B_ovl 合并；D 因子必须用相同 batch 的 B+D/B 配对，避免 batch 混杂。
- 状态：已实现；500 pilot 的 batch32 六组已补齐。

## D-04 标签与 checkpoint 契约

- 变化：unknown 统一为 -1；raw 1–8 → 0–7；checkpoint 使用 `state_dict`/`model_config`/`model_version`/`provenance`。
- 原因：与阮的固定评估器对齐；历史 32 验收的 -100 已用 -1 重跑验证 mIoU 完全一致。
- 影响：本地评估和阮评估共用一套标签/类别口径；旧 checkpoint 不再作为正式交付格式。

## D-05 历史文件隔离

- 变化：张系旧训练文件（`forty_tsvit_baseline.py`、`class_stats.py`、`loss_maskfocal.py`）不进入独立训练链路。
- 原因：旧文件带有旧 metrics 口径和旧训练入口，容易与新 U-Net 结果混用。
