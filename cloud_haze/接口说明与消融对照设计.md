## 一、输入口径（与 ForTy v1 解析结果一致）

- 光学：float32，shape (T=4, H=128, W=128, C=10)，已 /10000 归一化的反射率
- 标签：int64，shape (128, 128)，9 类含 unknown=0（只作掩码，不参与训练与指标）
- 波段顺序（DeepSatModels/TSViT 惯例）：0:B2 蓝、1:B3 绿、2:B4 红、3:B5、4:B6、5:B7 红边、6:B8 近红外、7:B8A、8:B11、9:B12
- 红边/近红外索引可覆盖：CloudHazeEngine(red_idx=2, nir_idx=6)；若服务器数据波段顺序与此不符，只改这两个参数，NDVI 统计自动跟随

## 二、两个变体（variant 开关）

| 变体 | 公式 | 物理含义 | NDVI | 用途 |
| --- | --- | --- | --- | --- |
| additive（默认） | x' = (1-β)·x + β·c，c 为波段相关云亮度向量 | 大气散射 + 云顶反射混合 | 会偏移（统计落表） | B 组主实验 |
| multiplicative | x' = a·x，逐像素全波段同乘，a ∈ [0.25, 1] | 信号衰减型退化 | 严格不变（解析性质） | 物理约束消融组 |

- 云亮度向量 c = [0.80, 0.78, 0.75, 0.70, 0.66, 0.62, 0.58, 0.55, 0.38, 0.30]：可见光高反射、短波红外明显下降（积云典型光谱形状）
- 档位预设：light（云覆盖 20% / 云核混合 0.30 / 雾幅度 0.02）、medium（35% / 0.50 / 0.04）、heavy（55% / 0.75 / 0.06）
- 雾模型：加性变体为波段相关路径辐射小增量（可见光为主、SWIR 弱，模拟轻雾；合成样本实测全图 |ΔNDVI| 中位数 0.07/0.14/0.22 对应轻/中/重档，云区 0.45–0.52——云核混合下 NDVI 崩坏属物理预期，即论文动机本身），乘法变体为 2–6% 均匀信号衰减
- 云覆盖率可显式覆盖：cloud_coverage ∈ [0.10, 0.70]，越界报错
- 雾只施加于受扰季节；multiplicative 变体的雾同为乘法衰减，保证该变体全程 NDVI 不变（自测 |ΔNDVI| 中位数 ~3e-08，浮点舍入量级）

## 三、张正锋：训练调用（B 组增强）

```python
from cloud_haze import CloudHazeEngine

engine = CloudHazeEngine()

# 在 Dataset 的 __getitem__ 内，拿到 (s2, label) 之后：
s2_deg, label, meta = engine.augment(
    s2, label, seed=sample_seed, level="medium", variant="additive")
# 直接把 s2_deg 当输入训练即可；label 原样传回，引擎不碰标签。
# 不退化对照（A 组）：level=None 时原图直返，走同一入口保证代码路径一致。

# seed 策略（建议）：sample_seed = 训练种子 * 1_000_000 + sample_id，
# 逐样本派生且可复现；把 (sample_id, seed, level, variant) 写进训练日志。
```

要点：

1. 增强概率自行控制（如 50% 样本走 level=None、50% 走 medium），退化与否在同一入口切换
2. 单季受扰：seasons=1（随机 1 季）；默认 seasons=None 为全部 4 季独立掩码
3. 本机自测覆盖了恒等、可复现、覆盖率、标签不动等 8 条标准；服务器接入后建议先用 1 个 batch 对照图人工确认再开跑
4. meta.per_season[s].coverage_actual 与 binary_masks 建议随训练日志落盘，供事后审计

## 四、阮业诚：评估协议（固定图样，可复现）

```python
from cloud_haze import CloudHazeEngine, iou

engine = CloudHazeEngine()

# 1) 冻结评估图样（不执行退化，只出掩码；与训练侧同 seed 时掩码严格同源）
masks = engine.export_masks(s2.shape, seed=7, level="medium", seasons=[0])
# masks[0] = dict(soft, binary, coverage_target, coverage_actual, shift)

# 2) 用冻结图样回放退化（所有受扰季共用传入掩码）
s2_deg, meta = engine.degrade(s2, seed=7, level="medium", seasons=[0],
                             mask=masks[0]["soft"])

# 3) 跨季重叠场景（C 组）：多季共基准掩码；平移上限 8px，
#    若 IoU < 0.60 引擎自动把平移量逐次减半直至满足合同，最终平移量在 meta.per_season[s].shift
s2_c, meta_c = engine.degrade(s2, seed=3, level="medium", seasons=[0, 2],
                              overlap=True, overlap_shift=8)
overlap_iou = iou(meta_c["binary_masks"][0], meta_c["binary_masks"][2])  # 核对 >= 0.60
```

manifest 建议字段（eval_manifest.csv 接口）：sample_id、场景（原始/单季受扰/双季独立/双季重叠）、variant、level、seed、coverage_actual、overlap_iou、ndvi_abs_median、ndvi_abs_p95。其中 NDVI 两列用 cloud_haze.ndvi_bias_stats(前, 后, mask) 直接产出。

## 五、物理约束消融对照设计（"物理约束优于无约束扰动"如何变成消融表）

消融问题：同样的云掩码、同样的覆盖率与种子，加性混合（无 NDVI 约束）与乘法受约束（NDVI 严格不变）两种退化，训练出的模型在受扰场景谁更稳？

| 组别 | 训练退化 | 变体 | 其他配置 |
| --- | --- | --- | --- |
| A | 无退化 | — | 基线 |
| B | 加性云雾 | additive | 现有主实验 |
| B-mult | 乘法云雾 | multiplicative | 与 B 同 seed 同覆盖率预算 |
| （可选）B-half | additive，强度减半 | additive | 分离"扰动强度"与"物理形式"两个因子 |

对照规则：

1. B 与 B-mult 必须同 seed 序列、同 coverage 目标（如都用 medium 档 35%），只切 variant 开关——这是单因子对照
2. 退化本身的偏差先验已由自测落表：multiplicative 的 |ΔNDVI| 中位数量级 1e-8（浮点舍入水平，解析不变），additive heavy 档的中位数/P95 见 自测输出/ndvi_bias_stats.csv——表中数字即论文方法节的"退化参数可解析验证"证据
3. 读表口径：看三类森林宏 F1 在 单季受扰/双季重叠 场景下 B 与 B-mult 的差；若 B ≥ B-mult，主张"带云光谱先验的混合比纯衰减更有效"；若反转，主张"NDVI 不变的保守退化更防捷径学习"——两个方向都能写，不押注
4. 该消融归入第一篇扩展实验（A/B 主表出来后按决策点 1 判断是否加跑），不是首发必做
