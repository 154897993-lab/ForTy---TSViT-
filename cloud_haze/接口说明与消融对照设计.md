## 一、输入口径（与 ForTy v1 解析结果一致）

- 光学：float32，shape (T=4, H=128, W=128, C=10)，已 /10000 归一化的反射率
- 标签：int64，shape (128, 128)，9 类含 unknown=0（只作掩码，不参与训练与指标）
- 波段顺序（DeepSatModels/TSViT 惯例）：0:B2 蓝、1:B3 绿、2:B4 红、3:B5、4:B6、5:B7 红边、6:B8 近红外、7:B8A、8:B11、9:B12
- 红边/近红外索引可覆盖：CloudHazeEngine(red_idx=2, nir_idx=6)；若服务器数据波段顺序与此不符，只改这两个参数，NDVI 统计自动跟随

## 二、两个变体（variant 开关）

| 变体 | 公式 | 物理含义 | NDVI | v2 用途 |
| --- | --- | --- | --- | --- |
| additive（默认） | x' = (1-β)·x + β·c，c 为波段相关云亮度向量 | 大气散射 + 云顶反射混合（厚云） | 会偏移（统计落表） | 六组主表全部使用 |
| multiplicative | x' = a·x，逐像素全波段同乘，a ∈ [0.25, 1] | 信号衰减（薄云/霾） | 严格不变（解析性质） | 物理约束消融臂 |

要点：两个变体不是"有约束 vs 无约束"，而是两种物理机制。加性变体带光谱形状先验（可见光高反射、SWIR 下降），乘法变体带 NDVI 不变约束。消融要回答的是这两种先验各自的贡献，不是谁"更物理"。

- 云亮度向量 c = [0.80, 0.78, 0.75, 0.70, 0.66, 0.62, 0.58, 0.55, 0.38, 0.30]：可见光高反射、短波红外明显下降（积云典型光谱形状）
- 档位预设：light（云覆盖 20% / 云核混合 0.30 / 雾幅度 0.02）、medium（35% / 0.50 / 0.04）、heavy（55% / 0.75 / 0.06）
- 雾模型：加性变体为波段相关路径辐射小增量（可见光为主、SWIR 弱，模拟轻雾；合成样本实测全图 |ΔNDVI| 中位数 0.07/0.14/0.22 对应轻/中/重档，云区 0.45–0.52——云核混合下 NDVI 崩坏属物理预期，即论文动机本身），乘法变体为 2–6% 均匀信号衰减
- 云覆盖率可显式覆盖：cloud_coverage ∈ [0.10, 0.70]，越界报错
- 雾只施加于受扰季节；multiplicative 变体的雾同为乘法衰减，保证该变体全程 NDVI 不变（自测 |ΔNDVI| 中位数 ~3e-08，浮点舍入量级）

## 三、高辉：训练调用（B_ind 与 B_ovl 两种训练模式）

```python
from cloud_haze import CloudHazeEngine

engine = CloudHazeEngine()

# B_ind 独立云模式：受扰季节各自生成独立掩码
s2_deg, label, meta = engine.augment(
    s2, label, seed=sample_seed, level="medium", variant="additive",
    seasons=seasons_sampled)          # 每样本抽 2–4 季，见下方口径对接

# B_ovl 重叠云模式：多季共用基准掩码 + 平移扰动，IoU ≥ 0.60 自动收缩
s2_deg, label, meta = engine.augment(
    s2, label, seed=sample_seed, level="medium", variant="additive",
    seasons=seasons_sampled, overlap=True, overlap_shift=8)

# A / D 组不加云：level=None 原图直返，走同一入口保证代码路径一致
s2_deg, label, meta = engine.augment(s2, label, seed=sample_seed, level=None)
```

口径对接（v2 第四节固定条件）：

1. 每样本以 probability=0.5 决定是否退化；退化样本抽 2–4 个受扰季节，传入 seasons 参数。引擎不负责这个抽样，由阮业诚 budget-matched 包装层 v1.1 完成。
2. 覆盖率 U(0.1, 0.7) 与三档强度随机同样由包装层抽样，引擎只接受显式传参；包装层调 degrade 时必须把 cloud_coverage 显式传入，不要依赖引擎档位默认值，否则分布口径对不上。
3. seed 策略：sample_seed = 训练种子 * 1_000_000 + sample_id，逐样本派生且可复现；包装层应把 (sample_id, seed, level, variant, seasons, coverage) 写进 cloud_audit.jsonl。
4. meta.per_season[s].coverage_actual 与 binary_masks 随训练日志落盘，供事后审计。
5. 服务器接入后先用 1 个 batch 出对照图人工确认，再开跑。

## 四、阮业诚：评估协议（S0–S3 四场景）

```python
from cloud_haze import CloudHazeEngine, iou

engine = CloudHazeEngine()

# 1) 冻结评估图样（不执行退化，只出掩码；与训练侧同 seed 时掩码严格同源）
masks = engine.export_masks(s2.shape, seed=7, level="medium", seasons=[0])
# masks[0] = dict(soft, binary, coverage_target, coverage_actual, shift)

# 2) S1/S2 场景：用冻结图样回放退化（所有受扰季共用传入掩码）
s2_deg, meta = engine.degrade(s2, seed=7, level="medium", seasons=[0],
                             mask=masks[0]["soft"])

# 3) S3 重叠场景：多季共基准掩码；平移上限 8px，
#    若 IoU < 0.60 引擎自动把平移量逐次减半直至满足合同，最终平移量在 meta.per_season[s].shift
s2_s3, meta_s3 = engine.degrade(s2, seed=3, level="medium", seasons=[0, 2],
                                overlap=True, overlap_shift=8)
overlap_iou = iou(meta_s3["binary_masks"][0], meta_s3["binary_masks"][2])  # 核对 >= 0.60
```

场景对应关系：S0 clean 不调用引擎；S1 单季 seasons 长度 1；S2 双季独立独立掩码；S3 双季重叠 overlap=True。v2 第二节已确认 S3 由引擎生成的重叠云雾承载，真实云区版遮挡留作讨论与未来工作。

manifest 字段（eval_manifest.csv 接口）：sample_id、group（A/D/B_ind/B_ind+D/B_ovl/B_ovl+D）、场景（S0–S3）、variant、level、seed、seasons、coverage_actual、overlap_iou、ndvi_abs_median、ndvi_abs_p95。NDVI 两列用 cloud_haze.ndvi_bias_stats(前, 后, mask) 直接产出。

严口径附录：同一批 checkpoint，另跑一组覆盖率固定 0.70、重档强度、单点退化的评估，作为稳健性附录。引擎侧无需改代码，包装层传固定参数即可。

## 五、物理约束消融对照设计（对齐 v2 六组框架）

消融问题：在同样的覆盖率和种子预算下，加性混合（带云光谱形状先验）与乘法衰减（带 NDVI 不变约束）训练出的模型，在受扰场景谁更稳？这回答的是"哪一种先验在起作用"，而不是"谁更物理"。

主表六组按 v2 全部使用 additive。变体消融作为附加臂，只加在 B_ind 上：

| 组别 | 训练退化 | 变体 | 训练模式 | 说明 |
| --- | --- | --- | --- | --- |
| A | 无退化 | — | — | 干净基线 |
| D | 无退化 + 边缘细化支路 | — | — | 结构对照 |
| B_ind | 加性云雾 | additive | 独立掩码 | 主实验 |
| B_ind+D | 加性云雾 + 边缘细化支路 | additive | 独立掩码 | 组合 |
| B_ovl | 加性云雾 | additive | 重叠掩码 | 季节结构 |
| B_ovl+D | 加性云雾 + 边缘细化支路 | additive | 重叠掩码 | 组合 |
| B_ind-mult | 乘法云雾 | multiplicative | 独立掩码 | 变体消融臂（附加，3 种子） |

对照规则：

1. B_ind 与 B_ind-mult 必须同种子序列（20261113/14/15）、同季节抽样、同覆盖率抽样、同训练超参，只切 variant 开关。单因子对照。
2. 只在 B_ind 上加臂，不加在 B_ovl 上。理由是变体作用于单季退化形态，与季节结构维度正交；先确认变体主效应，再考虑是否扩展交互臂。
3. 退化本身的偏差先验已由自测落表：multiplicative 的 |ΔNDVI| 中位数量级 1e-8（解析不变），additive 各档中位数/P95 见 自测输出/ndvi_bias_stats.csv。这张表是方法节"退化参数可解析验证"的证据，不是消融结果。

判据（预注册，出数前锁定，避免事后编故事）：

记 Δ = B_ind − B_ind-mult，取 S1/S2/S3 三个受扰场景的三类森林宏 F1 三种子均值之差。

| 情形 | 判读 | 论文写法 |
| --- | --- | --- |
| \|Δ\| ≤ 1 | 两种先验等效 | 消融进附录，正文一句带过，不作主张 |
| Δ ≥ +2 | 光谱形状先验有效 | 主张"云的光谱形状是有效成分，纯衰减不足" |
| Δ ≤ −2 | NDVI 约束有独立价值 | 主张"NDVI 不变的保守退化抑制了光谱捷径，加性偏移本身构成强扰动源" |

三个方向都能写，不押注。若出现 S1 与 S3 方向相反，按 S3 判读并如实报告分歧。

成本：一个附加臂 = 3 种子 @ 3,000+500，按 v2 阶段二b 的 18 组 6–15 时 / 20–45 元估算，单臂约 1–2.5 时、3–8 元。是否加跑挂在决策点 1 上，由六组主表方向决定：B 组有效性不成立时，变体消融无意义，直接取消。

与 v2 验收门槛的关系：本消融不参与 B 有效性（B−A）与 D 有效性（D−A）判定，只作机制解释。B_ind-mult 不进主表。

## 七、v1 → v2 对齐变更

1. 实验框架：v1 的 A/B/D/B+D 四组改为 v2 的 A/D/B_ind/B_ind+D/B_ovl/B_ovl+D 六组，B 拆独立云与重叠云两种训练模式。

5. 退化预算：v2 引入 budget-matched 分布口径（覆盖率 U(0.1,0.7)、三档随机、每样本 2–4 季、probability=0.5），引擎侧接口不变，由包装层控制。
